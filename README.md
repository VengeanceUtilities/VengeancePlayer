## 🌟 Overview

**Vengeance Player** delivers the best of both worlds: a seamless hybrid platform merging **YouTube Music** and **Spotify** into a single, high-performance Android experience. Enjoy your favorite tracks completely ad-free, with studio-grade audio fidelity and full offline support.

---

## ✨ Features

- 🎧 **Hybrid Architecture:** Stream seamlessly across YouTube Music and Spotify catalogs under one consolidated interface.
- 🚫 **Completely Ad-Free:** Background playback and unlimited skips without interruptions.
- 💾 **Offline Caching:** Download songs, albums, and playlists directly to your local device.
- 🎚️ **High-Fidelity Audio:** Native equalizer support and high-bitrate audio stream extraction.
- 🎨 **Modern Interface:** Polished UI featuring dynamic theming, smooth transitions, and a custom boot-up sequence.
- 🔄 **Built-in Auto-Updater:** Seamless in-app update checker integrated directly with GitHub Releases.

## 📥 Installation

1. Go to the [Releases](https://github.com/UpperEchelon-VengeanceUtilities/VengeancePlayer/releases/latest) section.
2. Download the latest `Vengeance_Player_Nightly.apk`.
3. If prompted by Android, allow installation from unknown sources.
4. Open the APK and install.

---

## 🛠️ Tech Stack & Architecture

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose & Material 3
- **Audio Pipeline:** AndroidX Media3 / ExoPlayer
- **Networking:** Ktor / OkHttp
- **Database:** Room Persistence Library
